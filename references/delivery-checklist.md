# 交付检查

## 运行与结构

- Node.js 18+ 下可安装。
- Remotion v4、TypeScript。
- `npm run dev` 可启动预览。
- `npm run build` 可执行导出；脚本应调用合适的 Remotion render 命令并输出清晰视频路径。
- Composition 为 1920×1080、30 fps。
- `NotoSerifSC` 字体有可靠加载路径，首帧不回退字体。
- 配置、cue、场景映射、音效事件均可定位和修改。
- 根目录 README 说明结构、文案修改、时长参数和音效重生成命令。
- 包含 `tools/make_audio.py` 与生成后的 `public/soundtrack.wav`。
- zip 不包含 `node_modules`、缓存、旧导出和临时截图。

## 内容与清晰度

- 第一幕包含钩子、铺垫、标题揭晓，约 10–20 秒。
- 第一幕为一镜到底或连续镜头，不是横向卡片卷轴。
- 标题动作专门演出主题。
- 作者存在时，标题下方有清晰署名。
- 全片火柴人为同一设计。
- 每个场景有独立道具和动作。
- 正文 ≥44 px，字幕约 66–68 px，重点词按需 60–200 px。
- 亮字有深描边，暗字有实底；没有半透明鬼影字。
- 底部约 200 px 字幕区不压住关键内容。
- 相机最大推近时，关键界面和数字仍完整可见。

## 时间与声音

- 每个 cue 时长来自统一公式或显式 `dur`。
- 所有 cue 使用整数帧，起止连续。
- composition 总帧数与 cue 总和一致。
- 音效事件由 cue ID 和 cue 内时间推导。
- 无配音、无配乐。
- WAV 重生成脚本可独立运行。

## 验证状态

交付时如实列出：

- 已完成类型检查。
- 是否完成全片渲染。
- 是否查看代表性帧。
- 是否试听音效。
- 是否存在因环境缺失而未验证的字体、编码或导出步骤。

不要用“全部通过”替代具体验证范围。
